# Changelog

All notable changes to FormBridge will be documented here.

## [1.0.0] - 2026-07-31

### Added

- Form templates and reusable data records
- CSS-selector autofill with accessible-name fallback matching
- React/Vue-compatible input events
- User-triggered Cookie, localStorage, and sessionStorage transfer
- Cookie clearing and automatic page reload
- Searchable, reorderable data cards
- JSON import and export
- Chinese and English interface
- Manifest V3 background service worker and content script retry
- Automated unit tests and production build
