# 手动测试清单

## 前置准备

1. 在 Chrome 打开 `chrome://extensions` → 加载 `dist/` 目录
2. 打开配置页（右键扩展图标 → 选项，或弹窗点"配置"）
3. 准备两个不同域名的测试页面（如 `http://localhost:3000` 和 `http://localhost:8080`），页面上有表单

---

## 一、配置页 — 模板管理

### 1.1 新建模板
- [x] 切换到"模板"tab → 点击"+ 新建模板"
- [x] 弹窗标题显示"新建模板"
- [x] 填写名称、网址、描述 → 添加多个字段（字段名 + CSS 选择器）
- [x] 配置按钮名称和按钮选择器（可选）
- [x] 点字段行的复制按钮 → 新增一行，名称后加 "(copy)"
- [x] 点字段行的 X → 删除该行
- [x] 名称为空时保存按钮置灰
- [x] 填写名称后保存 → 弹窗关闭 → 模板出现在表格中
- [x] 点表格中的"编辑" → 弹窗标题"编辑模板" → 修改后保存
- [x] 点表格中的"复制" → 弹窗标题"复制模板" → 名称后有 "(Copy)" → 保存后新增一条
- [x] 点表格中的"导出" → 下载 JSON 文件

### 1.2 模板草稿恢复
- [x] 点"+ 新建模板" → 填写名称、网址、字段 → **不点保存，直接点取消**
- [x] 再次点"+ 新建模板" → 表单恢复上次未保存的内容
- [x] 清空表单内容后点保存 → 保存成功
- [x] 再次点"+ 新建模板" → 空表单（上次已成功保存）
- [x] 编辑/复制模板 → 不受草稿影响，始终使用选中模板的数据

### 1.3 模板搜索
- [x] 在搜索框输入关键词 → 表格实时过滤
- [x] 搜索匹配名称、网址、描述
- [x] 清空搜索框 → 恢复全部显示

### 1.4 模板删除
- [x] 点单行"删除" → 弹出确认框 → 取消 → 不删除
- [x] 点单行"删除" → 确认 → 模板被删除
- [x] 勾选多行 → 点批量"删除" → 确认 → 选中模板全部删除

### 1.5 模板导入导出
- [x] 勾选多行 → 点"导出" → 下载 JSON（含多个模板）
- [x] 删除所有模板 → 点"导入" → 选择刚下载的 JSON → 模板恢复
- [x] 导入空 JSON 数组 → 提示"已导入 0 个模板"
- [x] 导入格式错误的 JSON → 提示"导入失败"

### 1.6 表格排序
- [x] 点"名称"列表头 → 升序/降序切换 → 箭头指示器变化

## 四、Cookie/Storage 复制粘贴（弹窗快捷键）

### 4.1 基本流程
- [x] 配置页 → Cookie tab → 打开开关
- [x] 在页面 A 打开弹窗 → 点弹窗内任意位置确保聚焦
- [x] **Ctrl+C** → toast 提示"Copied X cookies + storage from 域名A"
- [x] 切换到页面 B → 打开弹窗 → 点弹窗内任意位置
- [x] **Ctrl+V** → 页面 B 刷新 → toast 提示"Pasted X/X cookies + Y storage keys. Page reloading..."
- [x] 页面 B 应具有页面 A 的 Cookie 和 localStorage/sessionStorage

### 4.2 无快照粘贴
- [x] 首次打开弹窗直接 Ctrl+V → toast 提示"No snapshot. Copy first (Ctrl+C)."

### 4.3 快捷键不拦截输入框

- [x] 搜索框中按 Ctrl+C → 正常复制文本（不触发 cookie 复制）
- [x] 搜索框中按 Ctrl+V → 正常粘贴文本

### 4.4 作用域保真与快照过期（本次修复新增，待人工验证）

前置：准备同父域的两个子域（如 `https://app.example.com` 与 `https://admin.example.com`），父域 `.example.com` 上存在登录 Cookie。可用本地 hosts + 两个端口模拟替代时，注意 Cookie 域与端口无关。

- [ ] 在 `app.example.com` 复制 → 在 `admin.example.com` 粘贴 → 浏览器 Application → Cookies 中该 Cookie 的 Domain 仍为 `.example.com`（而非 host-only 的 admin 子域）
- [ ] 父域登录态在 `admin.example.com` 上可用（未掉登录）
- [ ] 跨站粘贴（`example.com` → `localhost:3000`）→ Cookie 写成 localhost 的 host-only，toast 提示"written host-only (parent-domain scope lost)"及条数
- [ ] 源站 path 非 `/` 的 Cookie → toast 提示"extra path=/ copies added"且计数与实际新增条数一致
- [ ] 存在分区 Cookie（CHIPS）时 → 被跳过并在 toast 中计数，字段其余部分正常
- [ ] 复制后不粘贴，等待 30 分钟以上再 Ctrl+V → 提示"No snapshot. Copy first (Ctrl+C)."，storage 中的 `cookieSnapshot` 已被删除
- [ ] 复制后重启 Chrome → 再 Ctrl+V → 同样提示无快照
- [ ] 复制后立即粘贴 → 正常成功（未误判过期）

## 六、跨上下文同步

同步方式说明：每个上下文在打开时各自从 `chrome.storage.local` 加载一次（弹窗每次打开都是新上下文，因此总是读到最新数据）；只有**语言**通过 `chrome.storage.onChanged` 实时下发。配置页是长驻标签页，不会自动感知另一个配置页标签的写入。

- [x] 弹窗修改宽度 → 刷新弹窗 → 宽度保持

- [x] 配置页修改语言 → 弹窗同步更新

- [x] 弹窗修改语言 → 配置页同步更新

- [x] 配置页修改 Cookie 开关 → 弹窗和 content script 同步

- [x] 配置页添加数据 → 弹窗刷新后新数据出现

- [ ] 语言为中文时打开弹窗 → 首帧即为中文（不再先显示英文再切换）
- [ ] 语言为中文时打开配置页 → 首帧即为中文

## 七、边界情况

- [x] 字段值为空 → 自动填充跳过该字段（不报错）
- [x] CSS 选择器不存在 → 尝试按 name/id/placeholder/label/aria-label 匹配
- [x] Checkbox 类型字段 → 值为 "true"/"1"/"on" 勾选，其他不勾选
- [x] 表单页面无 content script → 自动填充时自动注入再重试
- [x] 旧格式数据（`{fieldName: value}`）→ 加载时自动迁移为新格式

### 7.1 选择器容错（本次修复新增，待人工验证）

前置：新建一条数据，手动填写两行字段——第一行只填值不填选择器，第二行填正确选择器。

- [ ] 点击该数据卡片 → 第二行字段仍被正确填充
- [ ] 第一行被跳过，toast 为黄色警告且包含被跳过的字段名
- [ ] toast 不再出现"内容脚本未加载，请刷新目标页面"
- [ ] 语法错误的选择器（如 `input[`）行为同上
- [ ] 按钮选择器留空或非法 → 字段照常填充，toast 说明按钮选择器无效
- [ ] 字段名为空且选择器未命中 → 不填充页面上第一个输入框（该字段计入"未命中"）
- [ ] 尝试保存"有值无选择器"的数据 → 被拦下并高亮该行

### 7.2 批量导入与加载健壮性（本次修复新增，待人工验证）

前置：准备一个 JSON 数组文件，内容为：一条合法数据、一条缺 `values` 字段的数据、一条名称为空的数据。

- [ ] 批量导入该文件 → toast 提示已导入 1 条、跳过 2 条，并给出首条跳过原因
- [ ] 数据列表仍显示原有数据（不因坏条目变空）
- [ ] 导入非数组 JSON（如单个对象 `{...}`）→ 提示导入失败：JSON 格式无效
- [ ] 导入空数组 `[]` → 提示已导入 0 条
- [ ] 含"有值无选择器"条目的文件 → 该条被跳过且原因可读
