# Chrome Web Store listing — English

## Product name

FormBridge

## Summary

Copy cookies and Web Storage between pages, manage reusable form data, and autofill repetitive browser workflows.

## Detailed description

FormBridge helps developers, testers, support teams, and other authorized users move browser context between environments and complete repetitive forms faster.

Create reusable form templates with CSS selectors, save multiple data records, and fill matching pages from the extension popup. FormBridge also provides an optional Cookie Transfer workflow: capture cookies, localStorage, and sessionStorage from the active page, then restore them on another page that you choose.

Highlights:

- User-created form templates and reusable data records
- Precise CSS-selector autofill with accessible-name fallbacks
- Cookie, localStorage, and sessionStorage transfer triggered by the user
- Searchable and reorderable popup cards
- JSON import and export
- English and Simplified Chinese interface
- Local-first storage with no analytics, advertising, or external data service

FormBridge is intended only for accounts, websites, and test environments you are authorized to access. Transferred browser state can contain sensitive authentication information.
