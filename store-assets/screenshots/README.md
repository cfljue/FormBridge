# Screenshot checklist

Use real FormBridge UI only. Do not include personal accounts, production domains, tokens, session identifiers, or real cookies.

Chrome Web Store screenshots should be PNG or JPEG at **1280×800** (preferred) or 640×400. Keep every image at the same size.

Suggested files:

1. `01-data-management.png` — data records with clearly fictional values.
2. `02-template-management.png` — a reusable template and field mappings.
3. `03-cookie-transfer.png` — Cookie Transfer settings and its safety notice.
4. `04-popup-workflow.png` — popup cards on a matching page.

Before capture: use a clean browser profile, hide bookmarks and unrelated tabs, use a neutral fake domain such as `example.com`, and check all visible text at 100% zoom.
