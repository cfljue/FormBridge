# Chrome 应用商店文案 — 简体中文

## 产品名称

FormBridge

## 简短说明

在页面间迁移 Cookie 与 Web Storage，管理可复用表单数据，快速完成重复的浏览器操作。

## 详细说明

FormBridge 帮助开发、测试、支持团队及其他获得授权的用户，在不同环境间迁移浏览器上下文，并更快完成重复表单。

你可以用 CSS 选择器创建可复用的表单模板，保存多组数据记录，再从扩展弹窗填充匹配页面。FormBridge 还提供可选的 Cookie 迁移流程：从当前页面捕获 Cookie、localStorage 和 sessionStorage，然后恢复到你选择的另一个页面。

主要功能：

- 用户自定义表单模板与可复用数据记录
- CSS 选择器精确填充，并提供可访问名称兜底匹配
- 由用户主动触发的 Cookie、localStorage 和 sessionStorage 迁移
- 可搜索、可排序的弹窗数据卡片
- JSON 导入与导出
- 简体中文与英文界面
- 数据本地保存，不含统计分析、广告或外部数据服务

FormBridge 仅用于你有权访问的账号、网站和测试环境。迁移的浏览器状态可能包含敏感的身份验证信息。
