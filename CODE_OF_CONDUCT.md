# Code of Conduct

FormBridge is committed to a welcoming, constructive, and harassment-free community.

## Expected behavior

- Be respectful and assume good intent.
- Give actionable, technical feedback without attacking people.
- Welcome contributors with different experience levels and backgrounds.
- Protect private information, especially credentials, Cookies, tokens, and security reports.
- Accept maintainer decisions gracefully when they are explained in the project's scope and safety constraints.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks
- Publishing another person's private information
- Deliberately unsafe examples involving real credentials or unauthorized systems
- Spam, deceptive promotion, or coordinated manipulation of project metrics
- Repeated disruption after a maintainer request to stop

## Enforcement

Report conduct concerns privately to the maintainer through the GitHub profile associated with this repository. Maintainers may edit or remove content, close discussions, reject contributions, or temporarily or permanently restrict participation when necessary.

This policy applies in repository issues, pull requests, discussions, and other project spaces.
